# Stories inbox

Drop a new travel story into `inbox/`, then ask Claude:

> Convert the new stories in stories/inbox into lessons.

Claude writes the Spanish lesson, checks it, moves the story to `done/` and commits it.

## How to write a story

Copy `_template.md` into `inbox/` (e.g. `inbox/2026-10-lisbon.md`) and fill it in. Write in
French, English or Spanish, whatever is quickest. Bullet points are fine, and so are voice-memo transcripts.

Photos: put them in a folder with the same name (`inbox/2026-10-lisbon/`) and mention in the text
where each one goes (e.g. `[photo: tram.jpg]`).
